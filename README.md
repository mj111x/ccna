# CCNA 모의시험

`START-WEB.cmd`를 실행하면 브라우저에서 열립니다. 별도 설치와 인터넷 연결은 필요하지 않습니다.

시작 화면에서 종합 기출, 문제만, 실습만, D&D만 중 하나를 고를 수 있습니다. 종합 기출은 매번 객관식 92문제, LAB 4문제, D&D 4문제를 섞어 총 100문제로 구성합니다. 객관식은 답을 누르면 바로 다음 문제로 넘어가며 이전 문제 버튼과 번호 인덱스는 없습니다.

GitHub Pages에 올릴 때는 이 폴더 안의 파일과 폴더를 그대로 저장소 최상위에 업로드한 뒤 Settings → Pages에서 배포 원본을 선택하면 됩니다. `work` 폴더나 원본 ZIP은 업로드하지 않아도 됩니다.

정답은 제공된 스크린샷과 기존 LAB/D&D 자료를 기준으로 합니다.
